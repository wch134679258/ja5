Aurora 后端服务已启动

这里是 API 服务（端口 8081），不是用户页面。

用户界面

前端开发服务器默认跑在 5173，点下面这个地址进入站点：

http://localhost:5173

接口分组

  • /api/auth/* 注册、登录、图形验证码、当前用户
  • /api/search/* 分级分类检索、分类树、热门标签、搜索建议
  • /api/article/* 文章详情、相关文章
  • /api/favorites/* 收藏增删查（需登录）
  • /api/history/*、/api/likes/* 浏览历史与点赞（需登录）
  • /api/game/* 星空贪吃蛇成绩与排行榜
  • /api/user/profile 个人中心汇总（需登录）
  • /api/admin/* 文章 / 分类 / 标签管理（需管理员）

健康检查

返回图形验证码即表示服务与数据库均正常：

/api/auth/captcha
